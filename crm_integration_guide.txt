ÉTAPES D'INTÉGRATION:
--------------------

1. COPIER LES TEMPLATES
   - crm_web.html
   - crm_calendrier.html
   
   Commandes PowerShell:
   Copy-Item "AgW3b\templates\crm_web.html" "AgriWeb-Railway-Deploy\templates\"
   Copy-Item "AgW3b\templates\crm_calendrier.html" "AgriWeb-Railway-Deploy\templates\"

2. ADAPTER LES IMPORTS (dans agriweb_railway_deploy.py)
   
   Ajouter en haut du fichier:
   `python
   from database_adapter import get_db_connection, execute_query, IS_RAILWAY
   `

3. INTÉGRER LES ROUTES
   
   Ouvrir: crm_routes_extracted.py
   Copier tout le contenu APRÈS les imports
   Coller dans agriweb_railway_deploy.py AVANT "if __name__ == '__main__':"

4. ADAPTER LES CONNEXIONS DB
   
   Rechercher dans crm_routes_extracted.py:
   - sqlite3.connect(
   - conn = 
   - cursor.execute
   
   Remplacer par les fonctions de database_adapter (voir exemples dans le fichier)

5. TESTER LOCALEMENT
   
   cd AgriWeb-Railway-Deploy
   python agriweb_railway_deploy.py
   
   Vérifier: http://localhost:5000/crm

6. DÉPLOYER SUR RAILWAY
   
   git add .
   git commit -m "Add CRM routes with PostgreSQL support"
   git push origin main
